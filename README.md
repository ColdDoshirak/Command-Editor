# Command-Editor

Замена вкладки **Commands** из Streamlabs Chatbot для тех, кто сидит на **Windows 7** (или Linux).

Один из моих друзей до сих пор на Windows 7, и его Streamlabs Chatbot перестал подключаться к Twitch — вот я и написал это. Код писался с нейросетью как эксперимент, так что часть фич может вести себя странно. Прошлое — это прошлое, но сейчас оно работает заметно лучше.

> **Версия 2.0 (в работе).** Что нового — в [docs/release-notes.md](docs/release-notes.md).

## Возможности

**Команды**
- Совместимость с бэкапом команд Streamlabs Chatbot (импорт обратно в Streamlabs не поддерживается)
- Звуковые и текстовые (многострочные) команды, кулдауны (общие и на зрителя), цена в очках, громкость
- Права: Everyone → Regular → Subscriber → VIP → Moderator → Admin
- Переменные в ответах: `{user}`, `{target}`, `{args}`, `{1}`…`{9}`, `{count}`, `{points}`, `{currency}`, `{channel}`, `{random:1-100}`
- Псевдонимы: несколько имён у одной команды (`!music, !tune`)
- Случайный звук из папки (без повтора подряд)
- Авто-назначение звуков из папки по имени команды
- Проверка команды без Twitch: пустят ли зрителя, хватит ли очков, что уйдёт в чат
- Корзина удалённых команд, **Ctrl+Z** возвращает последнюю
- Поиск, история сохранений, полные бэкапы

**Звук и очереди**
- Очередь по группам: длинные звуки (музыка) не перебивают друг друга
- Громкость по группам и 32 аудио-канала: разные группы играют параллельно
- Сохранение очереди между перезапусками (по желанию, для группы)
- Глобальные горячие клавиши: пропустить, пауза, «остановить всё» — работают и в игре
- Оверлей для OBS (Browser Source): что играет, очереди, последние команды

**Twitch и валюта**
- Чат, зрители, активные чаттеры, модераторы, статус стрима; авто-переподключение
- Очки за просмотр, бонусы Regular / Mod / Active, множитель для сабов
- Награды за рейды и подписки (включая подарочные), ранги по порогам
- Таймеры: сообщения бота в чат раз в N минут, только если чат живой
- Статистика: популярные команды, оборот очков, топ зрителей

**Интерфейс**
- Русский и английский, по умолчанию — язык системы
- Четыре темы: Classic, Sidebar, Spreadsheet, Midnight (тёмная)
- Автосохранение и защита от второго запуска с той же папкой данных

## Системные команды

| Команда | Кто | Описание |
|---|---|---|
| `!points` | все | показать свои очки |
| `!add_points @user N` | модер | начислить очки |
| `!remove_points @user N` | модер | снять очки |
| `!random` | все | случайная команда из группы |
| `!top` | все | топ-5 по очкам |
| `!give @user N` | все | передать очки пользователю |
| `!uptime` | все | сколько идёт стрим (и жив ли он) |
| `!queue [GROUP]` | все | очередь группы / сводка по всем |
| `!skip [GROUP]` | модер | остановить текущий звук (общий канал или группа) |
| `!clear GROUP` | модер | полностью очистить очередь группы |
| `!volume [GROUP] <0-100>` | модер | громкость группы (по умолчанию — группа `SONG`) |

## Требования

- **Python 3.8** — последний Python для Windows 7; версии в `requirements.txt`
  закреплены под него (twitchio 3.x требует Python 3.11+ и не подходит)
- Зависимости из `requirements.txt`: PyQt5, pygame, twitchio, aiohttp, requests и др.

## Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/ColdDoshirak/Command-Editor.git
cd Command-Editor

# 2. Виртуальное окружение (рекомендуется)
python -m venv venv
# Windows: venv\Scripts\activate
# Linux:   source venv/bin/activate

# 3. Зависимости
pip install -r requirements.txt

# 4. Запуск
python command_editor.py
```

Данные (команды, конфиг, валюта, бэкапы) лежат рядом с программой. Другую
папку данных можно задать переменной окружения `COMMAND_EDITOR_HOME`.

## Сборка .exe

```bash
pip install -r requirements-dev.txt
python -m PyInstaller --noconfirm Command_Editor.spec   # -> dist/command_editor.exe
```

- В окружении не должно быть пакета `pathlib` (устаревший бэкпорт): с ним
  PyInstaller отказывается собирать (`pip uninstall pathlib`).
- spec собирает один файл из `command_editor.py`; пакеты `core/`, `bot/`, `ui/`
  PyInstaller находит сам, из данных нужна только папка `memes`.
- UCRT (`ucrtbase.dll`, `api-ms-win-*.dll`) PyInstaller берёт из `PATH`. Для
  Windows 7 без обновления KB2999226 они должны попасть в сборку — проверьте
  `build/Command_Editor/EXE-00.toc`.

python tests/run_tests.py      # офлайн: бот, очередь, данные (~1 мин)

## Быстрый старт

1. **Экспортируйте команды** из Streamlabs Chatbot (ПКМ по команде → *Export by group*).
2. В Command-Editor нажмите **Load File** — команды загрузятся и пересоздадутся в новом формате.
3. Вкладка **Twitch**: вставьте токен (Twitch Token Generator), укажите канал, **Connect**. Подключаться нужно при каждом запуске.
4. Вкладка **Group Settings**: включите очередь для нужных групп, назначьте аудио-каналы (для музыки рекомендуется группа `SONG` и отдельный канал).
5. По желанию: **Settings** — тема, язык, горячие клавиши, оверлей для OBS; **Timers** — сообщения в чат; **Currency Settings** — очки и награды.
6. Готово. Команды работают в чате. Проверить команду без стрима — кнопка **Test…**.

## Известные проблемы

- Награды за follow не начисляются: Twitch не сообщает о фолловах через чат
  (будет через EventSub). Награды за рейды и подписки работают.
- Токен берётся вручную с Twitch Token Generator, вход через Twitch прямо из
  программы — в планах.
- Команды без `!` не срабатывают.
- Подключаться к Twitch нужно при каждом запуске.
