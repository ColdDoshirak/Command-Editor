# Command-Editor

Замена вкладки **Commands** из Streamlabs Chatbot для тех, кто сидит на **Windows 7** (или Linux).

Один из моих друзей до сих пор на Windows 7, и его Streamlabs Chatbot перестал подключаться к Twitch — вот я и написал это. Код писался с нейросетью как эксперимент, так что часть фич может вести себя странно. Прошлое — это прошлое, но сейчас оно работает заметно лучше.

> **Эта ветка — бета с очередью (QueueTest).** Добавлена система очереди звуковых команд (музыка и другие длинные звуки), per-group громкость, 32 аудио-канала и опциональное сохранение очереди между перезапусками. Подробности — в [docs/queue.md](docs/queue.md).

---

## Возможности

- Совместимость с бэкапом команд Streamlabs Chatbot (импорт обратно в Streamlabs не поддерживается)
- Авто-назначение звуковых файлов из папки (по имени команды)
- Кулдауны (глобальные и на пользователя) и громкость
- Ответы от имени бота (многострочные)
- Добавление / удаление команд
- Вкладка **Twitch**: чат для команд, зрители, активные чаттеры, модераторы, статус стрима
- Автосохранение каждые 300 секунд и при выходе
- Play/Stop звука для проверки громкости
- Перебивание звуков (toggle) + сообщение, когда звук заблокирован
- Поиск по командам
- Менеджер бэкапов (включая историю)
- Система валюты (очки): начисление, награды, топ, передача
- Авто-переподключение при разрыве соединения
- **Очередь команд по группам** — длинные звуки (музыка) не перебивают друг друга
- **Per-group громкость** и 32 аудио-канала (параллельное воспроизведение разных групп)
- **Опциональное сохранение очереди** между перезапусками (включается на группу)

## Системные команды

| Команда | Кто | Описание |
|---|---|---|
| `!points` | все | показать свои очки |
| `!add_points @user N` | модер | начислить очки |
| `!remove_points @user N` | модер | снять очки |
| `!random` | все | случайная команда из группы |
| `!top` | все | топ-5 по очкам |
| `!give @user N` | все | передать очки пользователю |
| `!uptime` | все | сколько идёт стрим (и жив ли он) |
| `!queue [GROUP]` | все | очередь группы / сводка по всем |
| `!skip [GROUP]` | модер | остановить текущий звук (общий канал или группа) |
| `!clear GROUP` | модер | полностью очистить очередь группы |
| `!volume [GROUP] <0-100>` | модер | громкость группы (по умолчанию — группа `SONG`) |

## Требования

- **Python 3.8+** (Windows 7 / Linux)
- Зависимости из `requirements.txt`: PyQt5, pygame, twitchio, aiohttp, requests и др.

## Установка

```bash
# 1. Клонировать репозиторий
git clone https://github.com/ColdDoshirak/Command-Editor.git
cd Command-Editor

# 2. Виртуальное окружение (рекомендуется)
python -m venv venv
# Windows: venv\Scripts\activate
# Linux:   source venv/bin/activate

# 3. Зависимости
pip install -r requirements.txt

# 4. Запуск
python command_editor.py
```

## Быстрый старт

1. **Экспортируйте команды** из Streamlabs Chatbot (ПКМ по команде → *Export by group*).
2. В Command-Editor нажмите **Load File** — команды загрузятся и пересоздадутся в новом формате.
3. Вкладка **Twitch**: вставьте токен (Twitch Token Generator), укажите канал, **Connect**. Подключаться нужно при каждом запуске.
4. Вкладка **Group Settings**: включите очередь для нужных групп, назначьте аудио-каналы (для музыки рекомендуется группа `SONG` и отдельный канал).
5. Готово. Команды работают в чате.

## Известные проблемы

- Значения в таблице меняются только вручную (в самой таблице); панель под таблицей — для просмотра/копирования.
- В настройках валюты не работает смена команды и награды за follow/sub/raid; работают Regular и Mod bonus.
- Ranks — пока не работает.
- Команды без `!` не срабатывают.
- При первом настройке Twitch бот считает, что конфига нет; после перезапуска всё встаёт на места.
