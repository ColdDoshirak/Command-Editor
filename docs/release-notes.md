# Заметки к релизу

## 2.0 (в работе)

### Важно: изменилось начисление очков
- **Бонус регулярам начисляется только по таймеру.** Раньше регуляр получал
  бонус дважды: пропорциональный к начислениям за просмотр и ещё раз к любому
  начислению (возврат очков за несыгравший звук, перевод от другого зрителя,
  ручное начисление). Теперь остался только первый, поэтому балансы регуляров
  растут медленнее, чем в 1.x.
- **Нет начисления за время простоя.** Если между обновлениями списка зрителей
  прошло больше 10 минут (бот был отключён, компьютер спал), очки и часы за этот
  промежуток не начисляются. Раньше первое обновление после простоя выдавало
  очки за всё время отключения.

### Исправлено
- Бот больше не «глохнет» после разрыва связи с Twitch: переподключение
  автоматическое (в том числе после того, как Twitch сам закрывает
  соединение или просит переподключиться), в окне чата программы видно
  «соединение потеряно» / «восстановлено».
- **Награды за рейды и подписки работают** (раньше не начислялись никогда):
  рейд, подписка/продление (Tier 2 ×2, Tier 3 ×5), подарочная подписка —
  получателю и дарителю. Награды за фоллоу пока не начисляются: Twitch не
  сообщает о них через чат, их подключим отдельно (EventSub).
- Настройки Sys.Commands для `!queue`, `!skip`, `!clear`, `!volume` действуют
  (вкл/выкл, права, кулдаун, цена), копии этих команд работают. Кулдауны,
  которые раньше у них не действовали, при первом запуске сбрасываются в 0 —
  для зрителей ничего не меняется, дальше можно выставить свои.
- `!random` работает как обычный вызов выбранной команды: идёт через очередь
  и канал её группы, учитывает громкость группы, возвращает очки, если звук
  не сыграл, и увеличивает счётчик.
- Две быстрые одинаковые команды больше не проходят обе мимо кулдауна.
- «Allow sounds to interrupt each other» действует на всех аудио-каналах:
  раньше на канале группы без очереди новый звук всегда обрывал старый.
- Заменённый на диске звуковой файл подхватывается без перезапуска.
- Права команд работают: команду с уровнем Moderator/Admin не может вызвать
  обычный зритель (раньше уровень обычных команд не проверялся). Admin пока
  равен модератору.
- Модератор с бейджем в чате определяется сразу, без запроса к Twitch;
  команды с правом Everyone вообще не проверяют модератора — бот не
  «подвисает» на каждой системной команде.
- Классическая тема: поля панели **Command Details** (имя, права, описание,
  группа, кулдауны, цена, счётчик, Usage, Enabled, звуковые файлы, кнопки
  Browse) сохраняют правки — раньше всё, кроме ответа и громкости, терялось.
  Кулдаун и цена больше не ограничены 99. Новая команда сохраняется сразу.
- **Load File** снова загружает файл: раньше импорт тут же затирался старыми
  командами.
- Правки после загрузки файла или восстановления бэкапа попадают в нужную
  команду.
- При выходе из программы не пропадают команды с одинаковым именем.
- Новый токен из окна авторизации применяется сразу, без перезапуска.
- Перевод очков (`!give`) стал надёжнее; нельзя перевести себе или на
  несуществующее имя.
- Полное восстановление из бэкапа записывает восстановленную валюту и
  пересчитывает ранги зрителей под восстановленные пороги.
- **Полный бэкап больше не содержит токен Twitch.** Раньше в файл бэкапа
  (`backups/comprehensive/system_backup_*.json`) попадал весь
  `twitch_config.json` вместе с токеном доступа, хотя при восстановлении
  использовался только канал. Старые бэкапы с токеном стоит удалить, если
  вы их кому-то передаёте.
- Два полных бэкапа в одну секунду больше не перезаписывают друг друга.
- Кнопка Play Sound больше не меняется из фонового потока.
- **Проверка команды без Twitch** (кнопка Test…): вызовет ли сообщение
  команду, пустят ли зрителя с такой ролью, хватит ли очков, какой ответ
  уйдёт в чат и есть ли звук. Ничего не списывается и не считается.
- **Таймеры** (вкладка Timers): сообщения бота в чат раз в N минут, только
  если в чате было хотя бы M сообщений, по желанию — только на стриме.
- **Оверлей для OBS** (Settings → OBS overlay): страница для Browser Source —
  что играет, очереди, последние команды со зрителями; прозрачный фон,
  блоки и размер шрифта выбираются в адресе. Открывается только на этом
  компьютере (127.0.0.1).
- **Глобальные горячие клавиши** (Settings → Global hotkeys): пропустить
  звук, пауза очередей и «остановить всё» — работают и в свёрнутом окне, и в
  игре. По умолчанию выключены; занятые другой программой сочетания
  показываются на карточке.
- **Переменные в ответах команд:** `{target}`, `{args}`, `{1}`…`{9}`,
  `{count}`, `{points}`, `{currency}`, `{channel}`, `{random:1-100}` (раньше
  только `{user}`). Список — в docs/usage.md.
- **Псевдонимы команд:** поле Aliases (`!music, !tune`) — другие имена той же
  команды с её кулдауном, ценой и счётчиком.
- **Новые права команд: Regular, Subscriber, VIP.** Лестница Everyone →
  Regular → Subscriber → VIP → Moderator → Admin, каждый уровень включает
  нижние. Сабы и VIP определяются по бейджам в чате, регуляры — по статусу
  в валюте.
- **Важно: Admin больше не равен модератору.** Admin — это владелец канала и
  ники из списка `admins` в `moderators.json` (кнопка «Open moderators file»
  на вкладке Twitch); они показаны в списке модераторов как [Admin].
  Команды с правом Admin модераторы больше вызвать не могут.
- Команды из экспорта Streamlabs с правами Regular / Subscriber раньше были
  открыты всем — теперь эти права действуют.
- **Второй запуск программы с той же папкой данных не открывает второе окно**,
  а предупреждает, что программа уже запущена: две копии перезаписывали
  сохранения друг друга. Копии с разными папками данных работают как раньше.
- **Sub Bonus назван тем, чем он был всегда, — множителем** («Sub multiplier
  ×»): ×1 — как у всех, ×3 — втрое больше. Значение 0 оставляло подписчиков
  без очков за просмотр; теперь минимум ×1, а сохранённый 0 при запуске
  исправляется на ×1. Подсказка «Max …/h» считает множитель правильно (раньше
  прибавляла его как очки и занижала максимум).
- На вкладке валюты у Active Bonus появилась галочка «also offline».
- Новая установка начинает без бонусов: Regular 0, Mod 0, Active 0, Sub ×1.
  Раньше без файла настроек ставились Regular 1 и Mod 2. Сохранённые
  настройки не меняются.
- **Active Bonus начисляется.** Раньше поле было, но бонус не платился. Теперь
  зритель, писавший в чат после прошлого начисления, получает его так же
  пропорционально времени, как бонусы Regular и Mod (офлайн — только с
  `offline_active_bonus`). По умолчанию 0; сохранённая 1 (старое значение
  по умолчанию) при первом запуске сбрасывается в 0, чтобы балансы не начали
  расти без спроса — выставьте своё значение, если нужно.
- Вкладка Active Chatters показывает тех, кто писал в чат за последние
  10 минут (раньше — всех зрителей на момент подключения).
- Вкладка валюты: убраны поле «Command» (оно ни на что не влияло — команду
  баланса `!points` переименовывают в Sys.Commands, как и другие системные)
  и награда «On Host» (хосты Twitch убрал в 2022 году).
- Автоматический статус Regular «по часам» работает: раньше выбор Hours
  на вкладке валюты игнорировался и статус всегда давался по очкам.
- Вкладка зрителей валюты: «Add User» с заглавными буквами в имени больше
  не падает; Edit → Save больше не обрезает баланс до 999 999 и не
  отбрасывает дробную часть; статус модератора, выставленный на вкладке
  Twitch, сохраняется в файл.
- Группа на аудио-канале 32 (его предлагает Group Settings) теперь играет:
  раньше такого канала не существовало и звуки группы не воспроизводились.
- Play Sound в редакторе играет на своём канале и больше не обрывает звук
  зрителя на стриме (и не блокируется им).
- Устранена возможная полная заморозка программы: повышение ранга зрителя или
  списание за команду в момент сохранения валюты из другого потока могли
  навсегда заблокировать и окно, и бота.
- Проверка обновлений правильно сравнивает версии: раньше она не разбирала
  свою же `V1.1.6a` и предлагала «обновиться» на любой другой тег, в том
  числе более старый. Версия в About — `V2.0.0-dev`.
- Вкладка зрителей валюты: таблица больше не перестаёт обновляться, пока
  бот начисляет очки, кнопки Edit/Remove не пересоздаются каждые 30 секунд,
  а пустой список очищает таблицу.
- Автосохранение больше не забивает историю (вкладка History) одинаковыми
  копиями: бэкап создаётся, только если команды изменились. Раньше каждые
  5 минут появлялась копия, и за несколько часов из истории уходили настоящие
  старые версии.
- Удаление команды спрашивает подтверждение (раньше удаляло сразу).
- Проверка чужого баланса или команда модератора с опечаткой в нике
  больше не добавляют пустого зрителя в `users_currency.json`.
- `!volume` для группы без очереди применяется к следующему звуку.
- Ранги работают: выдаются по порогам, видны в `!points`, изменение рангов во
  вкладке сразу пересчитывает их всем.
- Награды за рейд/фоллоу/саб из вкладки валюты сохраняются в тех ключах,
  которые читает бот (старые настройки переносятся автоматически).
- Первый запуск в пустой папке создаёт `config.json`; повреждённый
  `config.json` не затирается молча, а сохраняется рядом как
  `config.json.corrupt-<время>`.
- Случайные падения при обновлении списка зрителей (виджеты менялись из потока
  бота) и ошибка статуса стрима каждые 30 секунд.
- Окно и бот общаются только через один мост: ни одна кнопка, настройка или
  правка команды не трогает бота из потока интерфейса. Статус стрима
  запрашивается у Twitch один раз в 30 секунд, а не дважды. Сообщение «Bot
  disconnected, reconnect manually» появляется, только когда бот остановился
  сам, а не после кнопки Disconnect.

### Надёжность
- Все файлы данных (`commands.json`, конфиг, валюта, ранги, бэкапы)
  записываются атомарно: обрыв питания или падение посреди сохранения
  оставляет прежний целый файл.
- Журнал падений `command_editor_crash.log` рядом с программой; исключение в
  интерфейсе больше не закрывает программу. Лог прошлого запуска сохраняется
  как `command_editor.log.1` (до трёх прошлых).
