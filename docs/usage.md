# Руководство по использованию

Полное руководство по вкладкам и настройкам Command-Editor. Короткая версия — в [README](../README.md).

## Как работать с командами

- **Экспорт из Streamlabs.** В Streamlabs Chatbot экспортируйте команды (ПКМ по команде → *Export by group* — так удобнее). Если групп несколько — лучше одну, мульти-групповой импорт не проверялся.
- **Load File** — загрузить команды из бэкапа. После загрузки создаётся новый файл в новом формате.
- **Save File** — сохранить команды в файл. Также автосохраняется каждые 300 секунд и при закрытии программы.
- **Save Legacy Format** — сохранить в старом формате. *Не рекомендуется*: вызывает несовместимость со Streamlabs Chatbot.
- **Auto-Assign Sounds** — автоматически назначить звуковые файлы. Выберите папку со звуками; работает только при совпадении имён (`!command` → `!command.mp3`/`.wav`).
- **Add / Remove Command** — добавить / удалить выбранную команду. Удалённая
  команда попадает в корзину: **Ctrl+Z** возвращает последнюю на прежнее
  место, **Trash…** (в темах — меню «…») показывает все удалённые (до 50).
- **Play Sound** — проиграть / остановить звуковую команду. Работает даже при подключённом боте.
- **Allow sounds to interrupt each other** — разрешить звукам перебивать друг друга (или запретить).
- **Show message when sound blocked** — предупреждение, когда звук не проигрался, потому что другой ещё играет.
- **Search** — поиск по названию команды.
- **History** — история сохранений. Держите побольше бэкапов.

### Права (Permission)

Уровни идут лестницей, каждый включает предыдущие:
**Everyone → Regular → Subscriber → VIP → Moderator → Admin**.
Regular — статус регуляра в валюте; Subscriber и VIP — по бейджам в чате;
Admin — владелец канала и ники из списка `admins` в `moderators.json`
(кнопка «Open moderators file» на вкладке Twitch).

### Переменные в ответах (Response)

| Переменная | Что подставляется |
|---|---|
| `{user}` | кто вызвал команду |
| `{target}` | первое слово после команды без `@` (если его нет — сам зритель) |
| `{args}` | всё после команды |
| `{1}` … `{9}` | одно слово после команды |
| `{count}` | сколько раз команда сработала, включая этот |
| `{points}` | очки зрителя |
| `{currency}` | название валюты |
| `{channel}` | канал |
| `{random:1-100}` | случайное целое число в диапазоне |

Пример: `!hug @Bob` с ответом `{user} обнимает {target}! ({count})` →
`alice обнимает Bob! (5)`. Неизвестное в фигурных скобках остаётся как есть.

### Горячие клавиши

**Settings → Global hotkeys.** Работают, даже когда окно свёрнуто или в фокусе
игра. По умолчанию выключены: пока они включены, эти сочетания не доходят до
других программ.

| Действие | По умолчанию |
|---|---|
| Пропустить то, что играет (во всех очередях) | Ctrl+Alt+S |
| Пауза / продолжение всех очередей | Ctrl+Alt+P |
| Остановить все звуки и поставить очереди на паузу | Ctrl+Alt+M |

Если сочетание уже занято другой программой, карточка об этом пишет —
выберите другое.

### Оверлей для OBS

**Settings → OBS overlay**: включите и нажмите **Copy** у адреса
(`http://127.0.0.1:8765/`). В OBS: *Источники → Браузер*, вставьте адрес,
ширина 400, высота 600. Фон прозрачный. Показывает, что играет, очереди и
последние команды со зрителями. Страница открывается только на этом
компьютере.

Параметры адреса: `?show=now,queue,recent` — какие блоки показать,
`&size=28` — размер шрифта. Например: `http://127.0.0.1:8765/?show=now&size=32`.

### Случайный звук из папки

Вместо файла можно указать папку (кнопка **Folder…** рядом с Browse): при
каждом вызове команда играет случайный звук из неё (`.wav`, `.mp3`, `.ogg`,
`.flac`) и не повторяет предыдущий, если в папке больше одного файла.

### Проверка команды без Twitch

Кнопка **Test…** (рядом с Play в панели команды и на панели Spreadsheet)
показывает, что будет, если зритель напишет сообщение: вызовет ли оно эту
команду (с учётом псевдонимов), пустят ли зрителя с выбранной ролью, хватит ли
очков, какой ответ уйдёт в чат с подставленными переменными и найден ли звук
(его можно сразу прослушать). Это сухой прогон: очки не списываются, кулдаун
не начинается, счётчик не меняется.

### Статистика

**Вкладка Stats**: за выбранный период (сегодня, 7, 30 или 90 дней) —
сколько очков начислено за просмотр, выдано за рейды и подписки, потрачено на
команды (возвраты вычтены) и передано между зрителями; сколько очков у
зрителей сейчас и сколько человек писало в чат за последние 10 минут;
популярные команды (за период и за всё время), топ зрителей по очкам и по
часам. Счётчики по дням хранятся в `stats.json` (90 дней).

### Таймеры

**Вкладка Timers** — сообщения, которые бот пишет в чат сам: раз в N минут
(*Every*), но только если с его прошлого сообщения в чате было не меньше M
сообщений (*After chat lines* — чтобы не писать в пустой чат), и при *Live
only* — только во время стрима. Первое сообщение — через один интервал после
подключения. В тексте работают `{channel}` и `{random:1-100}`. **Post now**
отправляет выбранное сообщение сразу. Изменения сохраняются сразу и
подхватываются работающим ботом.

### Псевдонимы (Aliases)

В поле **Aliases** через запятую — другие имена команды: `!music, !tune`.
Псевдоним вызывает ту же команду: тот же кулдаун, цена и счётчик.

## Вкладка Twitch (бот)

- Настройка подключения к каналу: **Channel** + **Connect**.
- **Токен** берётся с [Twitch Token Generator](https://twitchtokengenerator.com/).
- **Сохраняйте и подключайтесь** — подключаться нужно при каждом запуске программы.
- **Авто-переподключение** при разрыве соединения.
- **Зрители / активные чаттеры / модераторы** — списки в правой панели. После обновления токена может потребоваться повторная авторизация.
- **Статус стрима** (LIVE / OFFLINE) — тоже требует валидный токен.

> Управление очередью (`!queue`, `!skip`, `!clear`, `!volume`) описано отдельно — [queue.md](queue.md).

## Вкладка Group Settings

Настройки по группам команд:

| Колонка | Что делает |
|---|---|
| **Queue Enabled** | Включить очередь для группы (длинные звуки идут по одному, не перебивая) |
| **Max Queue Size** | Лимит очереди (0 = без лимита). При переполнении команда отклоняется, очки возвращаются |
| **Audio Channel** | Аудио-канал группы (0 = общий, 1–32 = выделенные, параллельное воспроизведение) |
| **Persist Queue** | Сохранять очередь группы между перезапусками (включается по желанию) |

Группы подтягиваются автоматически из команд. После **Save Settings** изменения применяются к работающему боту без перезапуска.

## Вкладка Sys.Commands

Системные команды (`!points`, `!random`, `!top`, `!give`, `!uptime`, `!queue`, `!skip`, `!clear`, `!volume`). Можно менять разрешение, кулдауны, стоимость, а для `!volume` — группу по умолчанию.

## Вкладка Currency (валюта)

- **Currency Settings** — настройки системы очков: начисление, награды (Regular / Mod bonus), стоимость команд.
- **Currency Users** — список пользователей с очками; можно начислять / снимать вручную.
- Не работает: смена команды в настройках, награды за follow/sub/raid.

## Вкладка Ranks

Замена ранга при достижении нужного количества очков. *Пока не работает.*

## Разное

- Значения в таблице команд меняются **вручную, в самой таблице**; панель под таблицей — для просмотра и копирования.
- Обычно правят `SoundFile` и `Cooldown` (в минутах).
- Работают и звуковые команды, и текстовые ответы (`Response`); есть встроенный чат для проверки.
- Программа безопасно сохраняет настройки даже при подключённом боте.
